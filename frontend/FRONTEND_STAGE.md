# GreenPulse Frontend — Stage 1

This frontend redesign is inspired by the visual language of the supplied reference image: dark editorial hero, large typography, rounded CTA buttons, glassy dashboard preview, spacious sections, and a premium community-oriented feel.

## Included
- Public landing page
- About, Features, Community, How it works, Contact sections
- No pricing section; GreenPulse is presented as free
- Individual + Community positioning
- Dashboard preview in the hero
- Modern login/register experience
- Existing React/Vite dashboard, calculator, history, reports and charts preserved
- Existing backend API service layer preserved

## Run
```bash
npm install
npm run dev
```

The frontend continues to use the existing React + Vite + Recharts stack and does not add a UI framework.
